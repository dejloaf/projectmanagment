# Фаза 1: Выбор концепции проекта

## Концепции проекта

В рамках первой фазы были предложены и рассмотрены следующие концепции программных проектов:

1. **StudyFlow** — веб-платформа для совместного планирования учебной нагрузки студентов (расписание, дедлайны, напоминания, командная работа над заданиями).

2. **SkillTrack** — сервис для отслеживания и анализа развития профессиональных навыков пользователя с возможностью постановки целей и самооценки прогресса.

3. **EventHub** — платформа для организации и координации небольших мероприятий (митапы, студенческие встречи, внутренние ивенты).

4. **SmartExpense** — мобильное приложение для учёта личных расходов и анализа финансовых привычек.

Все предложенные концепции являются относительно компактными, допускают реализацию в формате MVP и укладываются в требуемое количество пользовательских сценариев.

---

## Критерии, характеризующие проект

Для сравнения альтернатив были сформулированы следующие критерии:

1. **Уровень конкуренции** — насыщенность рынка аналогичными решениями и сложность выхода проекта.

2. **Техническая осуществимость (Technical Feasibility)** — реалистичность реализации проекта с точки зрения используемых технологий, сложности разработки и доступности необходимых инструментов и данных.

3. **Окупаемость по времени** — ожидаемое соотношение трудозатрат на разработку и потенциальной ценности результата (учебной и практической).

4. **Простота использования (Usability)** — интуитивность интерфейса, лёгкость освоения и удобство взаимодействия пользователя с системой.

---

## Оценка критериев и альтернатив

Каждый участник команды выполнил экспертную оценку важности критериев, а также оценил альтернативные концепции по каждому критерию.
Для учёта неопределённости использовались **трёхточечные оценки** (пессимистичная, ожидаемая и оптимистичная).

На основе полученных данных были применены два метода многокритериального принятия решений:

* метод **нечёткого коллективного TOPSIS** с использованием трёхточечных оценок;
* метод **чёткого коллективного МАИ (метод анализа иерархий)**.

---

## Результаты выбора концепции

* **По результатам метода TOPSIS** наиболее предпочтительной концепцией признан проект **SmartExpense — мобильное приложение для учёта личных расходов**.

* **По результатам метода МАИ** также был выбран проект **SmartExpense** как оптимальный вариант среди рассмотренных альтернатив.

---

## Анализ результатов и выводы

Результаты, полученные с использованием двух различных методов, оказались согласованными, что повышает доверие к сделанному выбору. Концепция **SmartExpense** показала наилучший баланс между технической осуществимостью, удобством использования и ожидаемой полезностью при умеренном уровне конкуренции.

Таким образом, в качестве базового проекта для дальнейших фаз практики была выбрана концепция **SmartExpense**, которая будет детализироваться, оцениваться и планироваться на последующих этапах.
